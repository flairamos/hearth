使用指南（hearth TUI）

启动 hearth 进入交互式界面。顶部为标题栏（模型 / 会话标题 / 模式徽章 / ctx 占用 / 连接状态），底部为输入框与状态栏（生成中显示实时 ~tok/s，完成后显示 ⚡ tok/s · last Xs 服务端精确值）。

键功能键功能

Alt+Enter / 行尾 \+Enter换行Ctrl+T思考模式开关
Esc中断生成（保留已生成内容）Ctrl+B侧栏开关

所有快捷键可在配置 keymap 节重映射；帮助面板实时显示当前绑定。注：Ctrl+M 在终端物理上等于 Enter（都发送 CR），故模型面板用 Alt+M。

斜杠命令

输入框以 / 开头自动弹出补全；Ctrl+K 命令面板共享同一注册表。

命令说明

/new · /sessions新建会话 · 会话列表（d 删除 / r 重命名）
/clear删除当前会话（消息、草稿本、保存文件，需确认），随后自动开新会话
/system <prompt>设置会话 system prompt（持久）
/temp <0-2> · /ctx <n>温度 · 上下文窗口（num_ctx）

@ 文件引用

  • 输入 @ 打开模糊文件选择器（跳过 .git / node_modules 等，子串匹配优先）
  • 选中插入 @路径；追加 #L121-135 或 #121-135 指定行范围
  • 发送时快照文件内容注入上下文，转录里只显示 📎 路径 (N chars) 标记
  • 文件缺失时提示 missing:，行号越界同样报告

会话管理

  • Ctrl+P 面板：Enter 加载 · d 删除（二次确认）· r 重命名；底部提示条常驻这些按键
  • /clear = 删除当前会话：消息、note 草稿本（短期）与保存的会话文件（长期）一起清除，二次确认后自动开一个新会话；跨会话长期记忆 memory.md 不受影响
  • 面板与侧栏的会话列表中，空会话（新建未发言、清空后）不显示——当前会话例外，始终可见
  • 会话按最近使用排序，自动以首条消息生成标题，重启完整恢复（含未完成标记）
  • /save 导出 Markdown（含工具调用与结果）

多模态

/img <path> 附加图片（≤8MB，自动 MIME 嗅探），下一条消息一并发送。模型具备 vision 能力时正常识别；不支持 vision 的模型会给出提示。

agent 模式（TUI 内）

  • Alt+A 或 /agent 切换，header 常驻橙色 [CHAT] / [AGENT] 徽章
  • 模型获得 13 个工具；写文件 / 执行命令按 access 权限档 弹出审批框：a 允许一次 · s 本会话始终允许 · d 拒绝
  • 危险命令（rm -rf、sudo、curl|sh、del /s、format C: 等）任何档位强制人工确认
  • 工具卡片显示调用与结果（⚙ 调用 / ✓ 成功 / ✗ 失败），模型每步可读写 note 草稿本

上下文管理

  • header 右侧 ctx 已用/窗口；状态栏进度条 >80% 黄、>95% 红
  • 发送前预检：接近上限自动裁剪最旧回合（保留 system prompt 与最近回合）
  • 达到 85% 自动摘要压缩：保留「摘要 + 尾部原文 + 草稿本 + 长期记忆」—— 长对话不断联
  • /compact 手动压缩 · /ctx 调整窗口 · /retry 回滚重生成

主题与外观

内置 dark / dracula / light 三套主题（/theme 循环），非 true-color 终端自动降级。侧栏 Ctrl+B 开关，窗口过窄自动隐藏。
