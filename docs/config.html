配置参考

配置文件位置：Linux/macOS ~/.config/hearth/config.json，Windows %AppData%\hearth\config.json。TUI 内 /config 用 $EDITOR 编辑，保存后热重载。

旧版迁移：若存在旧版 ollama-tui 路径下的配置且新路径为空，会自动沿用旧配置；首次保存后写入新路径。

字段说明

字段默认说明
ollama_urlhttp://localhost:11434后端地址；失效时自动探测常见端口并写回
api_styleautoauto（URL 以 /v1 结尾 → openai 风格）/ ollama / openai
discoverytrue后端自动发现开关
default_model空空 = 取后端第一个模型
themedarkdark / dracula / light
generation.thinktrue思考模式（qwen3.5 支持，输出独立 thinking 流）
generation.max_tokens4096num_predict 上限
context.num_ctx16384上下文窗口；qwen3.5 原生 256k，显存充足可调大（openai 风格下不可设）
context.auto_trimtrue接近上限自动裁剪最旧回合
context.auto_compacttrue达到 compact_at_pct 自动摘要压缩（保留尾部原文/草稿本/记忆）
context.keep_alive30m模型常驻时长（原生 API），"-1" 表示永久
keymap—快捷键重映射：动作名 → 键序列
system_prompt空全局 system prompt（会话级可覆盖）
auto_titletrue首条消息自动生成会话标题
agent.max_steps25工具步数预算（用尽自动追加无工具总结）
agent.permissionsaskask / risky / full（旧值 standard/yolo 自动映射）
agent.auto_approve[]免审批工具名单
agent.deny_patterns[]自定义危险命令正则（任何档位强制询问）
agent.bash_timeout_sec120单条命令超时
agent.temperature0.4agent 模式温度（更低提升工具调用稳定性）
agent.max_tool_result_chars8000工具结果截断长度（陈旧结果进一步截为 1/3）
agent.shellautoWindows: PowerShell → cmd（bash 需显式指定）；unix: bash
agent.memorytrue长期记忆工具开关
search.enginebingbing / duckduckgo / searxng（需 searxng_url）/ brave（需 brave_key）/ none
commands{}自定义 prompt 模板命令：{"名称": {"description":"…", "prompt":"…{{input}}…", "agent":false}}
model_favorites[]模型面板置顶（★）
ui.sidebartrue侧栏默认开关（Ctrl+B）

环境变量

变量说明
HEARTH_CONFIG配置文件路径覆盖
HEARTH_DATA数据目录覆盖（会话/记忆）
HEARTH_AGENT_APPROVE=1headless 下自动放行审批（每工具确认一次）
OLLAMA_TUI_CONFIG / OLLAMA_TUI_DATA / OLLAMA_TUI_AGENT_APPROVE旧品牌变量，仍然兼容
EDITOR/config 编辑器

会话与记忆数据

内容位置
会话（含 note 草稿本等全部上下文）<数据目录>/sessions/<id>.json（原子写，含 agent 工具记录；note 短期记忆存其中的 scratchpad 字段）
长期记忆<数据目录>/memory.md（Markdown 可手改，去重，上限 500 条）
导出/save 默认写当前目录 hearth-<标题>-<id>.md

数据目录（HEARTH_DATA 环境变量可整体覆盖）：Windows 为 %AppData%\hearth\，Linux/macOS 为 ~/.local/share/hearth（或 $XDG_DATA_HOME/hearth）；若旧版 ollama-tui 的数据目录已存在则继续沿用，自动兼容无需迁移。架构细节见 架构文档 8.6 节。
