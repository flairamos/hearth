为什么叫 hearth

hearth = 家中的炉火。模型烧在你自己的 GPU 上，数据不出家门 —— keep_alive 让炉火常暖不熄，对话与自动化都围炉而行。它不是又一个 llm-cli，而是一张炉边座位。

hearth~21 MB

交互式 TUI：流式对话（Markdown 渲染）、多会话、@ 文件引用、agent 模式（审批对话框）、多模态、实时 tok/s 仪表、命令面板。对标 opencode 的终端体验。

特性一览

🔥 后端自动发现

配置地址失效时自动探测 Ollama :11434 / LM Studio :1234 / llama.cpp :8080 / vLLM :8000 / Jan :1337，找到后写回配置。装好即用，零配置启动。

⌨️ 键盘驱动

命令面板 Ctrl+K、会话 Ctrl+P、模型 Alt+M、access Ctrl+G、复制 Ctrl+Y、输入历史 ↑/↓ —— 全部可重映射。

🛡️ access 权限三档

ask（变更前询问）/ risky（有风险才问，白名单自动）/ full（完全自主）。危险命令任何档位强制人工确认。

🧠 双层记忆

短期：note 草稿本每步注入，模型始终可见自己的计划；长期：memory.md 事实库跨会话跨进程，自动检索注入。

📎 @ 文件引用

输入 @ 打开模糊文件选择器；@path#L121-135 附加行范围；发送时快照内容注入上下文。

🗜️ 自动压缩

token 达 85% 自动摘要压缩，保留摘要 + 尾部原文 + 草稿本 + 长期记忆 —— 长对话不断联。

🌐 web 工具

web_fetch（HTML 清洗为纯文本）+ web_search（Bing / DuckDuckGo / SearXNG / Brave，无 Key 可用）。

🖼️ 多模态

/img 附加图片给视觉模型（qwen3.5:4b 支持 vision），无 vision 能力的模型给出行内提示。

🪟 Windows 优先

PowerShell 自动选择、CRLF 安全编辑、clip.exe 剪贴板、双击 run-tui.cmd 起终端、Scoop 安装。

30 秒上手

# 1. 本地运行 Ollama 并拉一个模型（hearth 也会自动发现 LM Studio 等）
ollama pull qwen3.5:4b

# 2. 启动交互式界面（自动发现后端）
hearth

# 3. 或直接让 agent 干活
hearth-agent agent -w ./myproject "统计 src 下所有 Go 文件的行数，写 report.md" --yolo
安装与构建详见 安装文档；常用操作见 使用指南。

设计原则

小模型能力最大化

面向 qwen3.5:4b 这类本地小模型做了成体系的优化：紧凑系统提示、原生 tool_calls + 文本协议双通道解析、工具错误原文回传驱动自纠、步数预算与收尾总结、上下文卫生（thinking 不回传 / 陈旧工具结果截断 / 超限自动裁剪）、易变上下文注入移到消息尾部以保住 Ollama 前缀缓存。对标 Anthropic《Building Effective Agents》：单循环 + 人工检查点，复杂度花在工具接口与上下文质量上。

隐私

无遥测、无云端调用，会话与记忆全部本地存储。

可分发

两个独立单文件二进制，Windows / Linux / macOS，GitHub Releases 提供 SHA256 校验。
